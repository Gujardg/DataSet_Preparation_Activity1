# Activity 1: Dataset Preparation

## Project Overview

This project completes **Activity 1 -- Dataset Preparation** for Unit I:
Foundations & Data Preparation.

The objective is to inspect a tabular dataset, identify data-quality
issues, perform basic exploratory data analysis (EDA), clean the data,
encode categorical features, scale selected numerical features, and save
a prepared dataset for future machine-learning work.

**No prediction model is trained in this activity.**

## Dataset Information

-   **Dataset:** Titanic Passenger Dataset
-   **Domain:** Transport
-   **Format:** CSV
-   **Source:** [Data Science Dojo -- Titanic
    CSV](https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv)
-   **Dataset description:** Each row represents a passenger aboard the
    Titanic. The columns include passenger class, sex, age, family
    members aboard, ticket fare, port of embarkation, and survival
    status.

The `Survived` column (0 = did not survive, 1 = survived) could be used
as a target in a future classification task. It is not used to train a
model here.

## Activity Steps Completed

1.  **Select a dataset:** Load the Titanic passenger dataset from the
    public CSV source.
2.  **Load and inspect:** Display the first and last records, dataset
    dimensions, column names, and data types.
3.  **Identify data types:** Separate numerical and categorical columns
    and display summary statistics.
4.  **Identify missing values:** Calculate missing-value counts and
    percentages for each column.
5.  **Handle missing values:** Work on a copy of the original data, fill
    missing `Age` and `Fare` values with their medians, fill missing
    `Embarked` values with its mode, and remove columns not needed for
    this basic activity.
6.  **Check duplicates and consistency:** Check and remove exact
    duplicate rows, and standardize text formatting in `Sex` and
    `Embarked`.
7.  **Perform EDA:** Display summary statistics and category
    frequencies; create an age histogram, a passenger-sex bar chart, and
    a fare box plot.
8.  **Encode categorical features:** Apply one-hot encoding to `Sex`,
    `Embarked`, and `Pclass`.
9.  **Scale numerical features:** Apply `StandardScaler` to `Age`,
    `SibSp`, `Parch`, and `Fare`.
10. **Save prepared data:** Verify the final data and export it as
    `Prepared_Titanic.csv`.

## Data Preparation Decisions

-   The original dataset is kept unchanged in `df`; all modifications
    are made to a copy.
-   `PassengerId` is an identifier and is not needed as an analysis
    feature.
-   `Name` and `Ticket` are excluded from this basic preparation
    exercise because they are identifier/text fields.
-   `Cabin` is excluded because it contains a large amount of missing
    information.
-   Median imputation is used for `Age` and `Fare` because the median is
    less sensitive to extreme values than the mean.
-   Mode imputation is used for the categorical `Embarked` column.
-   One-hot encoding is used to represent selected categories as 0/1
    columns.
-   Standard scaling is applied to selected numerical features, not to
    the possible target column `Survived`.

## Important Note About Scaling

This notebook demonstrates scaling on the prepared dataset for the
purpose of the data-preparation activity. In a real predictive
machine-learning workflow, first split the data into training and test
sets, fit `StandardScaler` only on the training features, and use that
fitted scaler to transform the test features. This prevents information
from the test set leaking into the training process.
